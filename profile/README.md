# Bredaz

**Estudio de software · Buenos Aires, Argentina** — *Software studio based in Buenos Aires, Argentina.*

We are a two-person software studio building AI-native applications. Our flagship product is **EncryptIA**, an app that teaches classical encryption methods, lets groups encrypt messages, and uses AI to identify which cipher was used.

Somos un estudio de dos personas. Construimos aplicaciones propias y software a medida, combinando métodos tradicionales con inteligencia artificial.
